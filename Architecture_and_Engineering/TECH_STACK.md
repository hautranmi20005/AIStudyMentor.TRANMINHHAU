# Technology Stack v1.1

**Mobile Client**:
- Android Studio, Kotlin, Jetpack Compose, Material 3, Navigation Compose.
- Retrofit (Network), Room (Cache), Coil (Images), CameraX (Camera).

**Backend**:
- Java, Spring Boot (Modular Monolith), Spring Security, Spring Data JPA.
- MySQL (Persistence), Flyway (Migrations).
- Redis (Caching).
- Firebase Admin SDK (Storage validation, FCM).

**AI**:
- Google Gemini API.
