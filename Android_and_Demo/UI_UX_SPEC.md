# UI/UX Specification v1.1

## 1. Navigation Flow
- Auth Graph: Login -> MFA -> (If U13 pending) Guardian Consent Screen.
- Main Graph (Bottom Nav): Ask AI, Quizzes, Dashboard, History, Profile.

## 2. Screen Specifications
- **MFA Screen**: Input code, countdown timer for resend.
- **Consent Screen**: Explains U13 policy, displays guardian email, checks status.
- **Ask AI**: CameraX view / Gallery picker + Text input.
- **Answer Detail**: Material 3 Cards for Step-by-step logic, key concepts.
- **Quiz Flow**: 1-question per screen with progress bar. Submit button on last screen.
- **Dashboard**: Charts/Bars showing Accuracy Rate and Subjects breakdown.
