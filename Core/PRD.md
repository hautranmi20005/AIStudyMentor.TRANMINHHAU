# Product Requirements Document (PRD)

## 1. Product Vision
Empower students with instant, safe, and structured academic assistance.

## 2. Core User Journeys
1. **Onboarding & Security**: Register, setup MFA, and clear U13 guardian consent if required.
2. **Q&A**: Ask math/science questions via text or photo, get Gemini-powered step-by-step answers.
3. **Practice**: Generate a quiz based on past questions, answer without seeing keys, and view graded results.
4. **Dashboard**: Track subject accuracy and usage.
