# MVP Scope v1.1

## Core MVP
1. **Registration & Auth**: Email/Password + JWT + MFA (FR-01A, FR-01C).
2. **Guardian Consent**: U13 workflow preventing feature access until approved (FR-01D).
3. **Profile**: Subject and style preferences (FR-01B).
4. **Questions**: Text and Image inputs (FR-02, FR-03).
5. **AI Answers**: Gemini step-by-step explanations and Alternative explanations (FR-04, FR-05).
6. **History & Bookmarks**: With basic offline Room cache (FR-06A, FR-06B).

## Extended MVP (Confirmed in v1.1)
7. **Practice Quizzes**: Generation of MCQ/Short-answer quizzes, attempts, and server-side scoring (FR-07).
8. **Progress Dashboard**: Aggregated metrics by subject and accuracy rate (FR-08).

## Explicit Exclusions
- Public leaderboards, social networking.
- Gamification / Badges.
- Voice/AR learning.
- Microservices / API Gateway.
- Offline AI generation.
