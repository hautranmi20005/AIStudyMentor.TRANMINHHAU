# Agent Collaboration Rules v1.1

1. **Orchestrator**: Approves contracts, manages cross-agent dependencies.
2. **Android Lead**: Owns `/android/**`.
3. **Backend Lead**: Owns `/backend/**` (Auth, Quizzes, DB).
4. **AI/Data Lead**: Owns `/backend/ai/**` (Gemini prompts, Orchestrator tuning).
5. **QA/Infra Lead**: Owns `/qa/**`, Docker, Firebase rules.

**Rule**: No Agent may change the Frozen Tech Stack or Extended MVP Scope without human approval.
