# Known Limitations

Entries P01–P05 are historical observations from earlier worktree states. The P19 section below records the current checkout and supersedes older environment/feature claims where they differ.

## P01 local backend verification

- The local backend did not start successfully during P01 with Java 25 and the generated `backend/.env`, even after verifying local MySQL, Redis, and Mailpit health. `spring-boot:run` failed while creating the JPA shared entity manager; the server did not respond on port 8080. No credential values were printed. Direct startup therefore remains unverified.
- The initial P01 end-to-end profile request returned HTTP 500 during Redis cache serialization. P04 fixed the cache-manager lifecycle issue that caused the typed JSON cache configuration to be bypassed.
- Docker-backed MySQL/Redis/Mailpit services became healthy, and the H2 `FlywaySchemaValidationIntegrationTest` passed. These checks do not substitute for direct application startup verification.

## P02 reproducible local runtime

- The new Compose services were started and health-checked on alternate localhost ports because the existing P01 stack already occupied 3306, 6379, 1025, and 8025. The new MySQL 8.0.36, Redis 7.4.2, and Mailpit v1.27.8 containers passed their health checks; the new backend actuator check correctly remained unavailable because no backend process was started.
- `backend/.env` currently has no Gemini API key. The dev profile intentionally fails before Spring context startup and lists missing variables instead of starting with a fake Gemini adapter. Supply a real key locally to start it.
- Android `:app:assembleDebug` and `:app:lintDebug` pass using JDK 17. `:app:testDebugUnitTest` is `NO-SOURCE`; no Android unit-test source files exist. `adb` is not available on PATH, so emulator installation, UI login, and screenshot evidence were not verified.
- The P02 verification run passed 37 backend tests. The current P04 `.\mvnw.cmd -B clean verify` run passes all 49 tests with zero failures, errors, or skips.
